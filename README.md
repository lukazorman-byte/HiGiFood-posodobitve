# HiGiFood-posodobitve

Podpisane izdaje programa HiGiFood HACCP. Program (Windows in strežnik) tu preveri `posodobitev.json`,
preveri podpis (Ed25519) in SHA-256 ter namesti novo različico. Tu ni podatkov strank ali ključev.

Zadnja izdaja: 2.8.0 (nov podpisni ključ: namestitve do 2.7.0 se enkrat posodobijo ročno)
